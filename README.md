# Syst-me-interactif-de-QCM-pour-examens-et-concours
‎Ce projet est une application Python avec interface graphique (Tkinter), conçue pour **gérer des QCM (questionnaires à choix multiples)** de manière interactive. L’application permet à plusieurs participants de passer un test chronométré, avec enregistrement automatique des scores et un système de classement sécurisé par mot de passe. ‎ ‎
